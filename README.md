One image summing up the world's news of **Tuesday 24 November 2026**:
34 stories across 7 regions — Iran's vow to fight the US naval blockade,
COP31 ending with no deal, Jensen Huang's return to Nvidia, and 31 more —
with a UTC timeline, six big numbers, a numbered world map, and a date check.

The image is drawn entirely in code (flat 2D vector, `draw.py`, Python
standard library only) and shipped as `entry.png`. The entrypoint `main.py`
(Python 3.13, standard library only) copies `entry.png` to
`$MAKEFUN_OUTPUT_DIR/entry.png`. No network, no secrets, no generated code.

## Run

```sh
python3 draw.py        # re-render entry.png (1024x1024, under 1 MiB)
MAKEFUN_OUTPUT_DIR=out python3 main.py   # writes out/entry.png
```

## Sources

Reuters, AP, BBC, CNN, Guardian, AFP, Space.com — every story was reported
on 24 November 2026 in at least one time zone; see the date check on the
image itself.
